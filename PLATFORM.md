# AGAS Navigator

Кабинет поставщика использует общий backend репозитория [AGAS](https://github.com/Su1teen/AGAS), папка `server/`. Подробная архитектура, миграции, ограничения импорта, безопасность и настройка почты описаны в [инструкции AGAS](https://github.com/Su1teen/AGAS/blob/main/PLATFORM.md).

Требуется Node.js 24. Установка: `npm ci --legacy-peer-deps`. Запуск: `npm run dev -- --port 3001`. API запускается в AGAS командой `npm run api`. `VITE_AGAS_API_URL` в `.env` должен быть одинаковым в двух интерфейсах. В production по умолчанию используется `/api`, который необходимо проксировать на общий backend.

Сохранён светлый стиль исходного кабинета, верхнее меню, карточки и компоновка графиков. Русский по умолчанию, RU/EN и KZT/USD в шапке; источник и дата курса доступны рядом с переключателем. Курс запрашивается у НБК через backend, произвольные курсы не подставляются. Валюта импорта и документов — KZT.

Нет вымышленных заказов и аналитики. Компания создаётся при регистрации поставщика. Владелец добавляет редакторов и аналитиков; API проверяет роли и компанию для каждого запроса. Каталог, импорт, заказы и CRM читаются из общей SQLite. После публикации товары появляются в AGAS, после гостевого формирования счёта соответствующие строки видит поставщик.

Проверки: `npm run lint`, `npm run typecheck`, `npm run build`. Полный браузерный тест двух платформ находится в AGAS: `npm run test:e2e`. Запустить изолированный `node tests/e2e-server.mjs` в AGAS и оба интерфейса на портах 3000/3001. Существующие предупреждения Fast Refresh в UI-компонентах не препятствуют сборке.

Для развёртывания необходимы общий API с постоянным диском, HTTPS, разрешённые origin и совместимые сайты для cookies. В интерфейсе подтверждение сохранения появляется после ответа сервера, ошибки отображаются явно. Тестовые данные в рабочее хранилище автоматически не добавляются.
